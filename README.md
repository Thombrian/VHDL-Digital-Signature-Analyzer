# VHDL Digital Signature Analyzer

A digital signature analyzer implemented in **VHDL** using a modular structural design. The system processes a serial input data stream using a **16-bit Linear Feedback Shift Register (LFSR)** to generate a digital signature. Control logic manages the measurement interval, stores the completed signature, and displays the resulting 16-bit value across a multiplexed four-digit seven-segment display.

This project was developed as part of **ESE 382: Digital Design Using VHDL and PLDs** at Stony Brook University.

## System Architecture

### 16-Bit LFSR

The `hp5004a_lfsr` module generates the digital signature from the incoming serial data stream.

The LFSR shifts its internal 16-bit register when the measurement gate is enabled and a selected input clock edge is detected. XOR feedback is applied to specific register positions to generate the resulting signature.

The generated signature is available through:


sig_out : out std_logic_vector(15 downto 0)


### Gate Generator FSM

The gate_gen module uses a four-state finite state machine:


S0 -> S1 -> S2 -> S3 -> S0


The FSM controls when the LFSR processes incoming data and when the final signature is transferred to the buffer.

- **S0:** Wait for start
- **S1:** Enable signature generation
- **S2:** Load completed signature into buffer
- **S3:** Return to idle state

The two primary control signals generated by the FSM are:

gate
buff_ld_en

### Edge Detection

The design supports both positive-edge and negative-edge detection.

Three input signals use selectable edge detection:

- Start
- Stop
- Data clock

The select_edge module combines the positive-edge and negative-edge detectors and selects the required edge based on the `pos_neg` input.

### Signature Buffer

The buffer_reg module stores the completed 16-bit signature.

When buff_ld_en is asserted, the current LFSR signature is loaded into the buffer:

LFSR Signature -> Buffer Register -> Display

This allows the final signature to remain available for display after the LFSR measurement cycle is complete.

### Multiplexed Display

The 16-bit signature is divided into four 4-bit hexadecimal values:

signature(15 downto 12)
signature(11 downto 8)
signature(7 downto 4)
signature(3 downto 0)

A 4-to-1 multiplexer selects one nibble at a time.

The selected nibble is converted into a seven-segment pattern by the funnyhex_seven module, while the decoder_1of4 module selects the corresponding physical display digit.

A digit counter continuously cycles through all four digits to create the multiplexed display.

## Simulation

The project includes hp5004a_tb.vhd for functional simulation of the complete design.

The testbench generates:

- System clock
- Data clock
- Reset sequence
- Start signal
- Serial input data stream
- Stop signal

A sample 16-bit input stream used by the testbench is:


constant data_stream : std_logic_vector(15 downto 0) :=
    "1000000000000000";


The test sequence is repeated to verify operation of the signature analyzer.
